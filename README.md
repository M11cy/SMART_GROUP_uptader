# SMART GROUP — обновления

Публичный репозиторий содержит подписанные обновления клиента и серверной части. Серверные пакеты
включают только скомпилированные API, агент и мигратор; дампы базы, настройки, ключи и исходники запрещены.

Этот репозиторий содержит только установщик и файлы обновлений Windows-клиента SMART GROUP. Исходный код, серверная часть, база данных и закрытая документация здесь не публикуются.

## Установка

1. Откройте последнюю публикацию в разделе **Releases**.
2. Скачайте `SmartGroup.Desktop-win-Setup.exe`.
3. Проверьте издателя цифровой подписи Windows и запустите установщик.

Приложение само уведомит о новой обязательной версии. Скачивание выполняется по первой команде пользователя, установка — по отдельному подтверждению; при следующем запуске обязательное обновление применяется до открытия рабочего пространства.

> [!warning] Безопасность
> Не устанавливайте файлы из сторонних зеркал. Рабочий установщик должен иметь действительную цифровую подпись издателя.
